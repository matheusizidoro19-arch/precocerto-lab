# Lucro no Azul

Plataforma de ferramentas gratuitas para cálculos de custo, margem, precificação, simulação de descontos e orçamentos.

- Site: https://lucronoazul.com.br/
- Publicação: GitHub Pages, branch `main`, diretório `/`.
- Domínio: `CNAME` com `lucronoazul.com.br`.
- Metadados e mapas do site: `sitemap.xml`, `sitemap.txt`, `robots.txt`.
- Analytics: `analytics.js` com consentimento, GA4 existente e eventos de calculadora e do kit.
- Venda: `kit-precificacao.html`, checkout Kiwify e produto **Kit PreçoCerto v1** (nome mantido até a atualização do arquivo Excel e do cadastro na Kiwify).

Não altere nomes de campos ou IDs das calculadoras sem testar o `app.js` e o simulador da página `marketplace.html`.
