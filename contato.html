Contato e sugestões

Encontrou um erro nas ferramentas ou tem uma sugestão? Utilize a área de Issues do projeto no GitHub. Esse canal é público e exige uma conta no GitHub para enviar uma mensagem.

Como relatar um problema

Informe a página ou ferramenta utilizada, o que você esperava e o que aconteceu. Para demonstrar um cálculo, use somente valores fictícios. Se houver um problema de visualização, indique o navegador e se estava usando celular ou computador.

Proteja suas informações

Não publique nomes, contatos, documentos, dados financeiros reais, dados de clientes, senhas ou comprovantes em Issues públicas. Se anexar uma imagem, confira se ela não contém informações pessoais ou comerciais sensíveis.

As Issues públicas não são um canal privado para solicitações que envolvam dados pessoais. Consulte a Política de Privacidade para conhecer o tratamento de dados e os controles disponíveis no site.
